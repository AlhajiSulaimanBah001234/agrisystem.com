SMART AGRICULTURE INFORMATION SYSTEM - SETUP
==============================================

1. Install XAMPP (Apache + MySQL + PHP)
2. Copy this folder to: C:\xampp\htdocs\agri_system
3. Start Apache and MySQL in XAMPP Control Panel
4. Open phpMyAdmin: http://localhost/phpmyadmin
5. Import database/schema.sql (creates agri_system database + tables)
6. Open: http://localhost/agri_system

DEFAULT ADMIN LOGIN
-------------------
Email:    admin@agri.sl
Password: password

FARMER ACCESS
-------------
Register at: http://localhost/agri_system/register.php

DATABASE CONFIG
---------------
Edit config/db.php if your MySQL credentials differ from:
  host: localhost, user: root, password: (empty), database: agri_system
